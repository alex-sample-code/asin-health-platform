# 常见异常模式 — 多维度关联分析

## 概述
单一指标异常可能是正常波动，但多个维度同时出现关联异常往往指向特定根因。本文档记录常见的异常模式及其典型根因。

## 模式 1：销量下降 + 差评上升 + 退货率高

### 表现
- 日均订单下降 >30%
- 退货率从 3% 上升至 >10%
- 平均评分下降 >0.3 星
- 近期差评占比 >20%

### 典型根因
1. **产品质量问题**: 某批次产品存在缺陷
2. **供应商更换**: 新供应商产品一致性差
3. **季节性因素**: 某些产品在特定季节更容易损坏（如高温导致融化）
4. **竞品改进**: 竞品升级后，消费者对比产生不满

### 排查步骤
1. 查看差评内容，归类退货原因
2. 比对不同批次的退货率
3. 检查是否有集中的退货原因代码

---

## 模式 2：广告费暴涨 + 转化率下降 + CPC 上升

### 表现
- 广告花费增加 >80%
- CVR 下降 >40%
- CPC 上涨 >50%
- ACOS 超过 40%

### 典型根因
1. **竞品加大投入**: 大卖入场或竞品开始激进投放
2. **关键词失效**: 原来的高转化词被竞品抢占
3. **Listing 变更**: 主图/标题修改导致点击率下降
4. **季节性竞争加剧**: 大促前广告竞争白热化
5. **自动广告失控**: 自动投放匹配到不相关流量

### 排查步骤
1. 检查搜索词报告，找出高花费低转化词
2. 对比竞品广告位变化
3. 检查 Listing 是否近期有变更
4. 分析 CPC 趋势与行业基准对比

---

## 模式 3：库存充足 + 销量骤降 + 无差评变化

### 表现
- 库存天数 >60 天
- 日均订单下降 >50%
- 评分和差评无明显变化
- BSR 排名大幅下滑

### 典型根因
1. **Listing 被压制**: 搜索排名被降权或 Listing 被标记
2. **Buy Box 丢失**: 跟卖者抢走 Buy Box
3. **类目变更**: Amazon 将产品移到错误类目
4. **搜索词被移除**: 后台搜索词被系统清理
5. **A+ 内容审核未通过**: A+ 页面被下架

### 排查步骤
1. 检查 Buy Box 占比变化
2. 搜索主要关键词确认产品可见性
3. 检查 Listing 是否有 Suppressed 警告
4. 验证产品类目是否正确

---

## 模式 4：销量上升 + 毛利率下降

### 表现
- 日均订单增长 >30%
- 毛利率从 25% 下降至 <10%
- FBA 费用或 COGS 上涨

### 典型根因
1. **FBA 费用上调**: Amazon 定期调整 FBA 费率
2. **原材料涨价**: 供应链成本上升
3. **汇率波动**: 跨境采购汇率变动
4. **促销过度**: 优惠券/折扣力度过大
5. **广告成本上升**: 为维持增长过度投放

### 排查步骤
1. 分解成本结构：FBA 费用、佣金、COGS、广告
2. 对比上月费率变化
3. 检查是否有未关闭的优惠券/促销

---

## 模式 5：退货率上升 + 单一原因集中

### 表现
- 退货率上升至 >8%
- 80% 以上退货集中在同一原因码
- 最近 30 天差评中提及相同问题

### 典型根因
1. **包装问题**: 运输过程中损坏
2. **尺寸/颜色描述不准**: Listing 信息与实物不符
3. **功能缺陷**: 某个特定功能故障
4. **配件缺失**: 装箱清单不完整

### 排查步骤
1. 导出退货原因报告
2. 分析原因码分布
3. 抽检最近入仓批次
4. 对比 Listing 描述与实物

---

## 模式 6：IPI 低分 + 仓储费暴涨

### 表现
- IPI 分数 <350
- 超龄库存占比 >20%
- 仓储费占销售额比例 >8%
- 有长期仓储费产生

### 典型根因
1. **滞销 SKU 未及时清理**: 过季/淘汰产品积压
2. **备货过多**: 预测失误导致超量入仓
3. **退货商品未及时处理**: 可售退货未重新上架

### 排查步骤
1. 导出超龄库存报告
2. 识别 >180 天和 >365 天库存
3. 计算清仓 vs 长期仓储费的 ROI
4. 设置自动移除规则

---

## 模式 7：多维度同时低分

### 表现
- 3 个以上维度评分低于 50
- 综合健康度为「危险」
- 多个指标持续恶化

### 典型根因
1. **产品生命周期末期**: 产品已过时，市场需求消失
2. **账号级问题**: 账号健康度警告影响全部 ASIN
3. **恶意竞争**: 被恶意差评、恶意投诉等攻击
4. **算法惩罚**: 违反平台政策被降权

### 应对策略
1. 评估产品是否值得挽救（计算修复成本 vs 收益）
2. 如果是账号级问题，优先处理账号健康
3. 考虑清仓退出（止损）
