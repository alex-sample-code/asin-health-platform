# 广告优化 SOP

## 1. 广告健康度指标

### 关键指标及基准
| 指标 | 优秀 | 良好 | 预警 | 危险 |
|---|---|---|---|---|
| ACOS | <15% | 15-25% | 25-40% | >40% |
| ROAS | >6 | 4-6 | 2-4 | <2 |
| CTR | >0.8% | 0.5-0.8% | 0.3-0.5% | <0.3% |
| CVR | >15% | 10-15% | 5-10% | <5% |
| TACoS | <8% | 8-12% | 12-20% | >20% |

> TACoS = 广告花费 / 总销售额（衡量广告依赖度）

## 2. 广告结构搭建

### 三层广告架构
```
品牌广告 (SB/SBV)
├── 品牌防御词
└── 品类核心大词

精准手动广告 (SP-Manual)
├── 精确匹配 — 已验证的高转化词
├── 词组匹配 — 中等确定性词
└── 商品定向 — 竞品 ASIN

自动广告 (SP-Auto)
├── 紧密匹配 — 高度相关
├── 宽泛匹配 — 发现新词
├── 同类商品 — 类似商品页
└── 关联商品 — 互补商品页
```

### 预算分配建议
| 广告类型 | 预算占比 | 目标 |
|---|---|---|
| SP 精确匹配 | 40% | 转化和盈利 |
| SP 词组匹配 | 20% | 拓展流量 |
| SP 自动广告 | 15% | 发现新词 |
| SP 商品定向 | 10% | 抢竞品流量 |
| SB 品牌广告 | 10% | 品牌展示 |
| SBV 视频广告 | 5% | 高 CTR 曝光 |

## 3. 关键词优化流程

### 每周操作
1. **导出搜索词报告**（过去 7 天）
2. **筛选高转化词**: 点击 >10, CVR >10%, ACOS <目标
   - 提升竞价 10-20%
   - 如在自动广告发现 → 转移到精确匹配
3. **筛选高花费低转化词**: 花费 >$10, 0 单
   - 添加为否定关键词（精确否定）
4. **筛选低 CTR 词**: 展示 >1000, CTR <0.2%
   - 考虑暂停或否定
5. **检查新词机会**: 自动广告中新出现的转化词

### 竞价调整策略
| 场景 | 操作 |
|---|---|
| ACOS < 目标50% | 提高竞价 20-30%（抢更好位置） |
| ACOS 在目标范围 | 维持当前竞价 |
| ACOS 超目标 30% | 降低竞价 10-15% |
| ACOS 超目标 100% | 降低竞价 30% 或暂停 |
| 新词测试期(前2周) | 允许 ACOS 超标 50%，积累数据 |

## 4. 广告异常处理

### ACOS 突然上升
**排查顺序:**
1. 检查是否有异常高花费的关键词（可能被恶意点击）
2. 检查 Listing 是否有变更导致 CVR 下降
3. 检查竞争环境（新竞品入场 → CPC 上升）
4. 检查是否有节日/大促导致 CPC 普涨

**应急操作:**
- 暂停花费最高且 ACOS >60% 的关键词
- 降低日预算上限
- 检查并优化 Listing（主图、标题、价格）

### 广告花费突然归零
**可能原因:**
1. 预算耗尽
2. 广告被暂停（违规）
3. 竞价过低
4. Listing 被抑制（Buy Box 丢失）

### 广告依赖度过高（TACoS >20%）
**优化方向:**
1. 提升自然排名（优化 Listing SEO）
2. 积累评论（Vine 计划、售后邮件）
3. 逐步降低自动广告和宽泛匹配预算
4. 优化高 ACOS 关键词，保留高效词

## 5. 新品广告策略

### 第 1-2 周：数据积累期
- 开启自动广告（4 种匹配全开）
- 竞价设为建议竞价的 1.2 倍
- 日预算：$30-50
- 目标：收集搜索词数据

### 第 3-4 周：优化期
- 从自动广告提取高转化词 → 手动精确
- 添加不相关词为否定词
- 开始精准手动广告
- 日预算：$50-80

### 第 2-3 月：扩展期
- 扩展词组匹配和商品定向
- 开启品牌广告（如有品牌备案）
- 逐步收紧 ACOS 目标
- 日预算根据 ROI 调整

## 6. 大促广告策略

### 大促前 2 周
- 提高日预算 50-100%
- 新增大促相关关键词
- 确保预算不在下午耗尽

### 大促期间
- 预算再提升 100-200%
- 每 2 小时检查预算消耗
- 动态调整竞价（高转化词加价）

### 大促后 1 周
- 恢复正常预算
- 暂停临时添加的大促关键词
- 分析大促期间数据，更新策略
