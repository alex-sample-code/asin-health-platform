# Listing 优化 SOP

## 1. Listing 质量评分标准

### 评分维度
| 维度 | 满分 | 权重 | 说明 |
|---|---|---|---|
| 标题优化 | 100 | 20% | 关键词覆盖、可读性、合规 |
| 主图质量 | 100 | 20% | 白底、高清、展示效果 |
| 副图完整 | 100 | 15% | 数量、信息传达 |
| A+ 内容 | 100 | 10% | 是否有 A+、质量 |
| 五点描述 | 100 | 10% | 关键词、卖点、格式 |
| 搜索词 | 100 | 10% | 后台搜索词填充率 |
| Buy Box | 100 | 15% | Buy Box 占比 |

### 标题优化规则
**格式**: 品牌 + 核心关键词 + 材质/规格 + 特性 + 适用场景 + 数量/颜色
- 长度: 150-200 字符（不超过 200）
- 首字母大写（介词/连词除外）
- 不使用特殊符号（!@#等）
- 不堆砌关键词
- 包含 3-5 个核心搜索词

## 2. 图片优化

### 主图要求
- 纯白背景 (RGB 255,255,255)
- 产品占图片面积 85% 以上
- 最小 1000×1000 像素（建议 2000×2000）
- 无文字、水印、Logo
- 展示真实产品（非效果图）

### 副图建议（6-8 张）
| 图片位置 | 内容 | 目的 |
|---|---|---|
| 副图 1 | 产品使用场景 | 建立代入感 |
| 副图 2 | 尺寸/规格信息图 | 减少退货 |
| 副图 3 | 功能/特性展示 | 突出卖点 |
| 副图 4 | 细节特写 | 展示质量 |
| 副图 5 | 包装内容物 | 设定预期 |
| 副图 6 | 对比图/竞品优势 | 促进转化 |
| 副图 7 | 品牌故事/资质 | 建立信任 |

## 3. 五点描述优化

### 格式规范
```
【核心卖点大写关键词】详细描述。包含搜索关键词自然融入。
长度: 每点 150-250 字符
```

### 内容顺序
1. **首要卖点** — 最大差异化优势
2. **产品质量** — 材质、工艺、认证
3. **功能特性** — 具体用途和效果
4. **适用人群/场景** — 谁会买、何时用
5. **售后保障** — 退换政策、质保

## 4. 后台搜索词

### 填写规则
- 不重复标题中已有的词
- 使用空格分隔（不用逗号）
- 包含同义词、近义词、拼写变体
- 不使用竞品品牌名（违规）
- 长度上限 250 字节
- 包含西班牙语/法语常见搜索词（美国站有大量非英语用户）

### 关键词来源
1. 亚马逊搜索建议（Search Bar Auto-complete）
2. 广告搜索词报告
3. 竞品 Listing 分析
4. 品牌分析报告（Brand Analytics）
5. 第三方工具（Helium10, Jungle Scout）

## 5. A+ Content

### 基础 A+ 模块选择
- 品牌故事 Banner
- 产品对比表（与自家其他产品对比）
- 图文混排模块（3-4 个）
- 技术规格表

### Premium A+ (品牌旗舰)
- 视频模块
- 交互式热点图
- 轮播图
- 问答模块

### A+ 注意事项
- 不包含价格、促销信息
- 不包含外部链接
- 审核周期 3-7 天
- 移动端优先设计

## 6. Buy Box 优化

### 影响因素
| 因素 | 重要性 | 优化方向 |
|---|---|---|
| 价格 | 高 | 保持竞争力但非最低 |
| FBA/FBM | 高 | FBA 优先 |
| 配送速度 | 高 | Prime 配送 |
| 卖家指标 | 中 | ODR <1%, 延迟率 <4% |
| 库存深度 | 中 | 保持充足库存 |
| 评价 | 中 | 高评分 + 多评论 |

### Buy Box 丢失排查
1. 检查是否有跟卖者（竞争 Buy Box）
2. 检查价格是否低于最低广告价格
3. 检查库存是否充足
4. 检查卖家绩效指标

## 7. Listing 被压制处理

### 常见压制原因
- 标题/图片不合规
- 分类错误
- 受限产品未提供证书
- 知识产权投诉
- 价格异常（高于参考价太多）

### 恢复步骤
1. 检查 Listing Quality Dashboard
2. 查看 Suppressed Listings 报告
3. 修复标记的问题
4. 提交 Case 请求恢复
5. 恢复后监控 7 天确保稳定
